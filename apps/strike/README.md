# Neon Strike

FPS néon : abattez les vaisseaux qui convergent vers vous.

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?logo=github&logoColor=white)](https://github.com/kewinMarchand/neon-games)

## Ouvrir Neon Strike

[Ouvrir Neon Strike](https://kewinmarchand.github.io/neon-games/apps/strike/)

## Le jeu

- Souris : viser
- Clic : tirer
- R : recharger
- Espace : pause / lancer
- Premier à 0 vie = défaite

## Thème

Le portail et les jeux utilisent une base CSS partagée (`neon/neon-tokens.css`, `neon-base.css`, `neon-components.css`).
