# Neon Pong

Pong néon : renvoyez la balle, marquez des points.

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?logo=github&logoColor=white)](https://github.com/kewinMarchand/neon-games)

## Ouvrir Neon Pong

[Ouvrir Neon Pong](https://kewinmarchand.github.io/neon-games/apps/pong/)

## Le jeu

- W/S ou ↑/↓ : palette gauche
- I/K : palette droite (mode 2 joueurs)
- Espace : lancer / pause
- Premier à 11 points gagne

## Thème

Le portail et les jeux utilisent une base CSS partagée (`neon/neon-tokens.css`, `neon-base.css`, `neon-components.css`).
