# Sorter

Jeu de tri néon sur étagères : sélectionne les objets de la première rangée pour les envoyer vers le haut et remplir des palettes de 3 éléments identiques.

## Règles

- Les choix sont présentés sur des plateformes/étagères empilées.
- La **première rangée** (devant) est visible et sélectionnable.
- La **rangée en dessous** est visible en transparence et non sélectionnable jusqu'à ce qu'elle soit révélée.
- Un objet sélectionné part vers le haut :
  - dans une **palette** en cours ou vide si elle peut accueillir 3 éléments identiques,
  - sinon dans un des **5 blocs de défausse**.
- Une palette complète (3 identiques) est expédiée et rapporte des points.
- La partie est bloquée si aucun placement n'est possible.

## Contrôles

- **Clic** : sélectionner un objet de la première rangée
- **P** : pause / reprendre
- **R** : recommencer
