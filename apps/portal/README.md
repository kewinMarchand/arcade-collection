# Neon Games — Portail

Portail web de la collection Neon Games : neuf mini-jeux néon jouables directement dans le navigateur.

- **Collection :** https://kewinmarchand.github.io/neon-games/
- **Dépôt :** https://github.com/kewinMarchand/neon-games

## Jeux

Les jeux sont disponibles dans ce monorepo sous `apps/<slug>/` :

- [Neon Invaders](../invaders/) — Défendez votre base contre des vagues d'envahisseurs.
- [Neon Breaker](../breaker/) — Cassez les briques et gardez la balle en jeu.
- [Neon Columns](../columns/) — Alignez des gemmes pour déclencher des réactions en chaîne.
- [Neon Drift](../drift/) — Pilotez, évitez les obstacles et récoltez les orbes.
- [Neon Runner](../runner/) — Sautez et glissez pour tenir la distance.
- [Neon Defender](../defender/) — Orientez le bouclier pour intercepter les photons.
- [Neon Mines](../mines/) — Déduisez l'emplacement des mines à partir des indices.
- [Neon Serpent](../serpent/) — Grandissez sans vous mordre.
- [Neon Orbiter](../orbiter/) — Alunissez en douceur : gravité et carburant.
