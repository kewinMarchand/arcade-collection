# @kewinmarchand/theme-arcade

Thème **arcade** : tokens, variables CSS et overrides, **attachés aux composants commons** de `@kewinmarchand/boilerplates-ui`. Visuel lumineux/arcade conservé.

- **Pas de composants « Arcade »** : toute brique UI réutilise un composant commun ; toute identité visuelle Arcade passe par ce thème.
- Tokens exposés sur la variable `--bui-*` (couleurs, surfaces, texte, typo, espacements, radii, ombres, focus, motion, conteneurs, z-index).
- Overrides `[data-a11y-mode="enhanced"]` et `prefers-reduced-motion`.
- Consommé par les monorepos `arcade-collection` et `arcade-tensors`.

Conforme à l'[ADR-0002](../../boilerplates-commun/doc/adr/0002-composants-communs-et-theme-arcade.md) du chantier de consolidation.
